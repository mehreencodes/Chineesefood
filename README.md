# 🍜 ChineseFood (React Project)

A modern and responsive Chinese Food Recipe App built with React.  
It displays delicious recipes with a clean UI and smooth user experience.

---

## 🚀 Live Demo

https://chineesefood.vercel.app/

---

## 💻 GitHub Repository

https://github.com/Declutterqueen/Chineesefood

---

## ⚙️ Tech Stack

- React.js  
- JavaScript (ES6+)  
- CSS3  
- Vite / CRA  

---

## 📌 Features

- 🍲 Recipe listing UI  
- 🖼️ Food images display  
- ⚡ Fast and responsive design  
- 📱 Mobile-friendly layout  

---

## 📦 Installation

git clone https://github.com/Declutterqueen/Chineesefood.git  
cd Chineesefood  
npm install  
npm start
